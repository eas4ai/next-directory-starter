# Production templates

Prefix: TPL

[TPL-001] The starter provides a versioned public-template module SDK for add-ons in addition to the existing stylesheet-only template path. A template may register typed renderers for the public shell and navigation, home discovery, directory results and cards, listing detail, featured, empty, pagination, footer, and optional comparison surfaces. Core routes retain data access, publication eligibility, authorization, metadata, structured data, canonical and crawl policy, and pass immutable public view models plus approved shared primitives to the renderer. A template declares compatible directory-profile ranges and cannot import storage, authentication, request, secret, administration, or mutation modules. Package validation checks the module identity, allowed imports, integrity, ownership, and profile compatibility before installation writes; generated registries remain deterministic; existing stylesheet-only packages remain compatible; and a selected template still falls back safely after removal. A new template can use the SDK without editing application routes.
Falsifier: A valid template cannot replace a named public surface through the SDK; an invalid, incompatible, identity-mismatched, forbidden-import, corrupt, colliding, or unsafe package changes the workspace; a renderer can read private or ineligible data, mutate state, or change access, metadata, canonical, crawl, or structured-data behavior; registry output depends on install order; an existing stylesheet-only package stops working; removing the selected template takes the application offline; or adding a template requires an application-route edit.
Mechanism: template-products
Status: Agreed 2026-10-15

[TPL-002] VECTOR is a complete installable AI-tools directory product built through the public-template module SDK. Its original assets, dark and light theme, responsive layout, typography, compact geometry, and interaction hierarchy reproduce the approved VECTOR concept: comparison-first discovery, dense server-rendered filters, current pricing and free-tier signals, platform and integration facts, open-source and verified-launch signals, product marks, and a functional comparison of two to four eligible tools. The dark design uses canvas `#0A1020`, surface `#141D30`, ink `#EDF2FF`, action `#81A4FF`, and verified signal `#74D5B1`; it uses five-pixel corners, condensed sans headings, neutral sans data, thin dividers, compact rows, and original product marks or controlled diagrams instead of stock photography. Action color identifies actions and selection, while signal color identifies verified facts only; the light design preserves the same hierarchy with readable contrast. Its versioned profile defines the facts that its cards, details, filters, sorts, search, badges, comparison, and launch views consume, including operator-owned verification fields. The add-on includes namespaced brand assets, realistic original seed records that exercise every public field and state, product documentation, change history, and license notice. Its reproducible archive validates, installs into a clean compatible starter, builds, exposes administrator preview and selection, explicitly activates and seeds, preserves public eligibility, metadata, Markdown, social, accessibility, keyboard, no-JavaScript, 320-pixel, light, and dark behavior, and removes its unchanged source without deleting seeded operator data.
Falsifier: The installed product materially contradicts the approved VECTOR design system or public composition; a shown filter, sort, comparison, pricing, free-tier, integration, open-source, verification, or launch control is decorative or returns the wrong eligible records; private, draft, rejected, suspended, unverified-as-verified, or otherwise ineligible data appears; comparison accepts an unknown, duplicate, fifth, or ineligible tool or loses the selected facts without explanation; a required public surface, original asset, representative seed state, package document, preview, or selection is missing; a public page requires client JavaScript, cannot be used by keyboard, has unreadable contrast, or overflows at 320 pixels; metadata, Markdown, social output, or structured data disagrees with the visible record; equal sources produce different archives; a clean validate-install-build-activate-seed-select-remove round trip fails; installation or removal changes the operator database implicitly; or removal deletes seeded operator data or unrelated source.
