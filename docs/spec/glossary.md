# Next Directory Starter — glossary

- **Operator:** the person or team configuring and running a directory made
  from the starter.
- **Directory:** the operator's public catalog of links on a chosen subject.
- **Listing:** one catalog entry describing an external resource and linking
  to it.
- **Category:** an operator-managed grouping used to browse listings.
- **Owner:** an account allowed to edit its own listing and submit it for
  publication.
- **Submission:** a draft listing or edit offered for review, not yet public.
- **Moderator:** an account allowed to approve, reject, or suspend listings.
- **Publication:** the state in which an approved listing is visible on public
  pages.
- **Featured placement:** a labelled promotional position for an eligible
  listing, separate from ordinary search results.
- **Article:** editorial content written by an authorized editor, distinct
  from a listing.
- **Eligible content:** published, unsuspended content that may appear on
  public pages and in the sitemap.
- **Server rendering:** producing page content as HTML on the server for the
  initial request, including requests from crawlers without JavaScript.
- **Canonical URL:** the preferred public URL for one page when multiple URLs
  could show equivalent content.
- **Theme preset:** the saved shadcn/ui design choices applied across the
  directory's public and administrative pages.
- **Theme editor:** the authenticated administrator's control for previewing
  and saving a theme preset.
- **Agent import:** an operator-managed listing drafted from a URL inspected
  by an external agent and kept private until an authorized catalog user publishes it.
- **WebMCP:** browser-page tools registered for an agent through
  `document.modelContext` when the browser supports that API.
- **Remote MCP:** an HTTP endpoint that exposes directory tools to a client
  such as Claude Code without requiring an open browser tab.
