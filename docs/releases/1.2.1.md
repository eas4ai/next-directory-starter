# Next Directory Starter 1.2.1

This is a security release. It upgrades Next.js from 16.4.0 to 16.4.2 to fix three advisories disclosed on October 22, 2026. It contains the changes since `1.2.0`.

## Security fixes

- **GHSA-2464-fhr4-w9xw (critical):** unauthenticated remote code execution in the Image Optimization API when SVG files are processed.
- **GHSA-673q-mjm6-r5xr (critical):** unauthenticated remote code execution in `use cache` functions that return typed arrays.
- **GHSA-p3m5-59mp-jv5r (high, CVE-2026-94482):** denial of service in the App Router through Server Actions.

`next`, `@next/env`, and `eslint-config-next` now install 16.4.2. This release adds no database migrations and no new configuration.

## Upgrade notes

Every installation running `1.2.0` or earlier should upgrade. An installation still on a `1.1.x` release must first apply the `1.2.0` upgrade notes, which include database migrations.

1. Follow the existing-installation steps in [UPGRADE.md](https://github.com/eas4ai/next-directory-starter/blob/1.2.1/UPGRADE.md). Stop writes and take the backup before you check out the new code.
2. Check out `1.2.1`, run `npm ci` and `npm run build`, and restart the web process and scheduled jobs.
3. For Docker deployments, follow the container upgrade steps in the [operator manual](https://github.com/eas4ai/next-directory-starter/blob/1.2.1/docs/operator-manual.md#container-deployment): set a new immutable `DIRECTORY_IMAGE` tag, build with `--pull` so the `node:24-bookworm-slim` base picks up the Node.js 24.22.1 security release, run the migration, and keep the prior image for rollback.
4. Add-on packages that require `>=1.2.0 <2.0.0` work without changes.
