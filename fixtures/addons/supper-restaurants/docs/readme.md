# Supper Restaurants

Supper is a complete restaurants and food directory for Next Directory Starter 1.2 or later. It includes a warm editorial theme, image-led server-rendered layouts, a versioned restaurant profile, an original plate mark, and eight original food and dining photographs.

Activate `supper-restaurants.restaurants@1.0.0`, select the Supper theme and template, and opt into the fictional sample catalog with `npm run addon:seed -- supper-restaurants`. Fourteen sample places cover cuisine, neighborhood, location, price, dietary accommodations, meal periods, service modes, reservations, time zone, hours, dishes, accessibility, media, and public eligibility.

All filters and sorting submit ordinary GET requests. Published hours always retain their time zone. Supper does not claim that a venue is open now, has a table, passed a health check, or has verified reviews. Removing the add-on restores unchanged source and preserves explicitly seeded records and media.
