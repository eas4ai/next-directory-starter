# Lessonpath Courses

Lessonpath is a complete courses and learning directory for Next Directory Starter 1.2 or later. It includes a friendly path-led theme, responsive server-rendered layouts, a versioned course profile, an original route mark, eight original subject illustrations, and fourteen original instructor portraits.

Install and validate the archive, run database migrations, activate `lessonpath-courses.courses@1.0.0`, and select the Lessonpath theme and template. Sample content remains explicit:

```sh
npm run addon:seed -- lessonpath-courses
```

The fourteen fictional courses exercise topic, level, format, duration, price, pace, schedule, language, certificate, prerequisite, outcome, provider, instructor, portrait, enrollment, and media facts; one draft demonstrates public eligibility. Filters and sorting use ordinary GET requests and retain state through pagination. Color supports the visual system while every topic, level, and format remains labeled in text.

Enrollment links open provider pages. Lessonpath does not claim enrollment, progress tracking, completion, or credential verification. Removing the add-on restores unchanged source and preserves explicitly seeded operator data and media.
