# Elsewhere Travel

Elsewhere is a complete travel experiences directory for Next Directory Starter 1.2 or later. It includes a sea-mist theme, immersive server-rendered layouts, a versioned experience profile, an original compass mark, and eight original destination photographs.

Activate `elsewhere-travel.experiences@1.0.0`, select the Elsewhere theme and template, and opt into the fictional sample catalog with `npm run addon:seed -- elsewhere-travel`. Fourteen experiences cover destination, meeting location, type, season, activities, duration, price, group size, difficulty, accessibility, inclusions, booking links, itineraries, media, and public eligibility.

All search, filters, sorting, and pagination use ordinary GET requests. Elsewhere links to provider information and does not assert live availability, reservation status, transportation, payment, or fulfillment. Removing the add-on restores unchanged source and preserves explicitly seeded records and media.
