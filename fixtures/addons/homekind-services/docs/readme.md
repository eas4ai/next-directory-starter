# Homekind Services

Homekind is a complete home services directory for Next Directory Starter 1.2 or later. It includes a calm conversion-focused theme, server-rendered provider layouts, a versioned services profile, an original house mark, and eight original real-work photographs.

Activate `homekind-services.providers@1.0.0`, select the Homekind theme and template, and opt into the fictional sample catalog with `npm run addon:seed -- homekind-services`. Fourteen providers cover services, area, location, pricing, response, emergency service, availability, experience, licenses, insurance, operator review evidence, ratings, quote links, accessibility, media, and public eligibility.

Homekind attributes each aggregate rating and review count to its stored public source and states the operator review date. Quote links do not promise a response, quote delivery, matching, hiring, payment, or job completion. Removing the add-on restores unchanged source and preserves explicitly seeded records and media.
