# NOW/NEXT Events & Conferences

NOW/NEXT is an installable event directory product for the Next Directory Starter. It combines a square-edged poster system with an event profile, date and topic discovery, speaker and schedule details, packaged original media, and representative seed content.

## Install and activate

Pack and install the add-on with the starter add-on CLI. Activate `now-next-events.events` version `1.0.0`, then select the `now-next-events` theme and template. Run the seed command only when you want the included demonstration catalogue.

## Discovery model

The public directory supports search, event type, topics, attendance mode, accessibility, start-date ranges, and chronological sorting. The home and detail renderers format dates in each event's stored IANA time zone. NOW/NEXT labels event timing as upcoming, in progress, or past from the stored start and end instants. Ticket links lead to the organizer; the template does not claim that a booking or an attendee has been verified.

## Seed ownership

Seeded listings and media become operator data. Re-running the seed is idempotent. Removing the add-on removes its source files and registry entries while retaining seeded records and media so the operator can migrate or archive them deliberately.

## Media

The included event photographs were generated specifically for this reference product. Alt text describes each image's useful visual content. Replace the sample media and `.example` organizer URLs before publishing a production directory.
